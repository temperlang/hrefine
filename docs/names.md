# Name candidates

For picking a name before 1.0; delete this file once we have one.
Checked 2026-10-29 for packages of the same name on PyPI, npm,
crates.io, and NuGet (all four free unless noted). Maven Central and
LuaRocks weren't reachable from the dev container, so check those too.

In the family of Chromarite (color, "-rite" as in rite or wright) and
Ordable (order, "-able"):

| Name | Thinking |
|---|---|
| **Linkrite** | Links, done right; a sibling of Chromarite |
| **Hrefine** | `href` plus refine: URLs made exact |
| **Urlwright** | A maker of URLs, as a wheelwright makes wheels |
| **Locable** | Locate plus "-able", a sibling of Ordable |
| **Canonica** | Canonical URLs, the standard's one form |
| **Hostrite** | Hosts read right, the security point |
| **Urlrite** | Plain and searchable, if less pretty |
| **Linkwright** | Like Urlwright, broader |
| **Hreflect** | `href` plus reflect: the URL as browsers see it |
| **Hrefable** | `href` plus "-able" |
| **Pathrite**, **Webrite**, **Urlstead**, **Urlwise**, **Locivo**, **Navable**, **Hostable** | Also free |
| **Urlicorn** | Free, and memorable, if too cute |

Taken somewhere, so ruled out: Waymark, Wayfarer, Lodestar, Wayfind,
Urlable, Anchorable, Origo, and Urlkit.

My favorites: Linkrite (family resemblance to Chromarite, and "links"
reads more broadly than "URLs" for the formatter and source-view parts),
then Hrefine and Locable.
