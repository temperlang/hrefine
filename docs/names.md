# Name candidates

For picking a name before 1.0; delete this file once we have one.
Checked 2026-10-29 for packages of the same name on PyPI, npm,
crates.io, and NuGet (all four free unless noted). Maven Central and
LuaRocks weren't reachable from the dev container, so check those too.

Each library gets its own name rather than one that sounds like its
siblings (Chromarite, Ordable), unless they're often used together; the
sites carry the shared look.

| Name | Thinking |
|---|---|
| **Hrefine** | `href` plus refine: URLs made exact |
| **Canonica** | Canonical URLs, the standard's one form |
| **Hostline** | Where the host line is drawn, the security point |
| **Urlspec** | Plain: URLs to the spec |
| **Linkmint** | Links freshly minted, exact |
| **Hrefsmith** | A smith of `href`s |
| **Urlwright** | A maker of URLs, as a wheelwright makes wheels |
| **Hreflect** | `href` plus reflect: the URL as browsers see it |
| **Locivo** | Invented, from "locate" |
| **Hrefy** | Short and searchable |
| **Urlicorn** | Memorable, if too cute |

Also free: Urlstead, Urlwise, Navable, Hostable, and Linkwright.
Partly taken: Netloc (crates.io), Waypost (npm), and Urlcraft
(crates.io). Taken in most: Waymark, Wayfarer, Lodestar, Wayfind,
Signpost, Trailhead, Origo, Urlkit, Urlable, Anchorable, Wurl, and Urlex.

My favorites: Hrefine, then Canonica and Hostline.
